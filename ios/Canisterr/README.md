# Canisterr SwiftUI scaffold

This folder contains the native iOS rebuild plan for Canisterr.

## Phase 1

- Authentication
- Dashboard feed
- Share composer
- Friends and follow requests
- Profile shell

## Phase 2

- Lists
- Watch logs
- Notifications
- Settings

## Notes

- The UI is intentionally dark and cinematic to match the current web app.
- A mock backend is included so the screens are usable immediately.
- Firebase-backed implementations are scaffolded behind the same backend protocol.
- TMDB and Firebase can be swapped in later without changing the view hierarchy.
